# Product Requirements

- As a developer, I want to choose a root directory and recursively discover Makefiles, so that all of my local projects are indexed with little setup.
- As a developer, I want targets and inferred descriptions, so that I can choose the right command without opening the file.
- As a frequent user, I want project and target favorites plus recent quick actions, so that common work is one click away.
- As a terminal user, I want each run to open in Terminal with interactive login Bash and the project working directory, so that it uses my normal command-line environment.
- As a developer, I want logs, exit codes, timestamps, and success/failure state saved locally, so that I can review past work.
- As a developer, I want completion notifications, deep links to logs, and unread badges, so that background work is easy to follow.
- As a keyboard-oriented Mac user, I want menus, shortcuts, context menus, search, and font scaling, so that the app behaves like a native macOS tool.
